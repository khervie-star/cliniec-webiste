# Cliniec Healthcare Website

A modern, responsive healthcare technology platform built with Next.js 14+, TypeScript, and Tailwind CSS.

## 🚀 Quick Start

```bash
# Install dependencies
pnpm install

# Run development server
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📋 Features

- ✅ **Fully Responsive Design** - Mobile-first approach with seamless tablet and desktop layouts
- ✅ **Modern Tech Stack** - Next.js 14+ App Router, TypeScript, Tailwind CSS
- ✅ **Smooth Animations** - Framer Motion for polished user experience
- ✅ **Optimized Images** - Next.js Image component for performance
- ✅ **Accessible** - Semantic HTML and keyboard navigation support
- ✅ **SEO Ready** - Proper metadata and heading structure

## 🛠️ Tech Stack

- **Framework:** Next.js 15.1.4
- **Language:** TypeScript 5.7.2
- **Styling:** Tailwind CSS 3.4.17
- **Icons:** Lucide React 0.468.0
- **Animations:** Framer Motion 11.15.0

## 📦 Project Structure

```
├── app/

│   └── globals.css      # Global styles
├── components/
│   ├── Header.tsx       # Navigation header
│   ├── Hero.tsx         # Hero section

```

## 🎨 Design Features

- **Primary Color:** #2d5f4f (Healthcare Green)
- **Typography:** Inter font family from Google Fonts
- **Responsive Breakpoints:** 640px, 768px, 1024px, 1280px

## 📱 Responsive Design

- **Mobile (<768px):** Hamburger menu, stacked layout
- **Tablet (768-1024px):** Adjusted spacing and typography
- **Desktop (>1024px):** Full horizontal navigation, 3-column stats
