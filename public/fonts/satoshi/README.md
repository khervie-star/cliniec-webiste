# Satoshi Font Files

This directory should contain the Satoshi font files in WOFF2 format.

## Required Files:
- `Satoshi-Light.woff2` (weight 300)
- `Satoshi-Regular.woff2` (weight 400)
- `Satoshi-Medium.woff2` (weight 500)
- `Satoshi-Bold.woff2` (weight 700)
- `Satoshi-Black.woff2` (weight 900)

## Download Satoshi:
You can download Satoshi from:
- https://www.fontshare.com/fonts/satoshi
- Or from your preferred font source

## Installation:
1. Download the Satoshi font family
2. Extract the WOFF2 files
3. Place them in this directory
4. The font will be automatically available as `font-satoshi` in your Tailwind classes

## Usage in Code:
```tsx
<div className="font-satoshi">Text in Satoshi</div>
```
